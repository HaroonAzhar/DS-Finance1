1. Purpose & Overview
    Identify fraudulent credit card transactions on corporate/personal credit cards as part of the annual company audit. 
    This case study considers the scenario where companies auto-approve expenses within certain thresholds. 
    Alternatively, this could be a model used to detect whether a transaction is fraudulent as part of the auto-approval process.
